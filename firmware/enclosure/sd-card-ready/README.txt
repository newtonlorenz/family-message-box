FAMILY MESSAGE BOX - ENDER-3 V3 SE - ELEGOO MATTE PLA

Copy the three .gcode files in this folder to the root of the printer's SD card.

Print order:
1. BOX_TRAY.gcode - electronics carrier
2. BOX_LID.gcode  - button and label-disc lid
3. BOX_BASE.gcode - main enclosure body

The files are already sliced for the Ender-3 V3 SE with a 0.4 mm nozzle.
Do not re-slice them at the printer.

Before each print:
- Wash and dry the build plate without touching the print area.
- Run automatic bed levelling.
- Keep air-conditioning airflow away from the open printer.
- Watch the complete first-layer brim. Stop if its lines do not merge smoothly.

Material: ELEGOO matte PLA
Nozzle: 220 C
Bed: 65 C throughout
Layer: 0.32 mm (0.24 mm first layer)
Supports: none
